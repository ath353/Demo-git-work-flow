# 1. Tên dự án ✅

**Git Workflow Demo**

# 2. Ứng dụng của dự án

Project nhỏ demo một phần của Git Workflow — quy trình chuẩn giúp các thành viên trong team sử dụng Git làm việc cùng nhau hiệu quả. Nếu không có Git Workflow, dự án có thể gặp:

- ⚠️ Code người này đè lên code người kia
- 💥 Code đang lỗi vẫn được đẩy lên nhánh chính khiến ứng dụng sập
- ❓ Không rõ phiên bản nào là ổn định nhất để gửi cho khách hàng

# 3. Hướng dẫn sử dụng

Project này được tạo ra để demo và minh hoạ cách áp dụng Git Workflow trong thực tế. Xem lịch sử commit và các nhánh (branch) trong repo để hiểu quy trình được minh hoạ.
